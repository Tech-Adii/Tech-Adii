# Install your GitHub profile README

GitHub profile: https://github.com/Tech-Adii

1. Open https://github.com/new
2. Set **Repository name** to **Tech-Adii** (exactly your username, including capitalization).
3. Select **Public**.
4. Select **Add a README file**, then click **Create repository**.
5. Open README.md, click the pencil (Edit), replace the contents with the supplied README.md text and commit the changes.
6. Visit https://github.com/Tech-Adii to see the new profile.
7. On your profile's Overview tab, select **Customize your pins** and pin your strongest repositories.

Suggested pin order: ModelTrace, Smart Shopping Trolley, KiranaMitra, RFID Attendance System, Obstacle Avoidance Robot, ESP32 Home Automation.

Note: Images and GitHub stats cards rely on third-party image services; if they fail to load, remove the relevant image tags.
