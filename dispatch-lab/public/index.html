Reading the results

All times are CPU ticks. Arrival is when a process becomes ready. Burst is the total CPU time it needs. Each process has one CPU burst, with zero context-switch cost.

  • Turnaround = completion − arrival
  • Waiting = turnaround − burst
  • Response = first run − arrival
  • CPU utilization = busy ticks ÷ total elapsed ticks × 100

Equal ranks use arrival time, then process order. In Round Robin, arrivals at a slice boundary join before the outgoing process returns to the queue.
